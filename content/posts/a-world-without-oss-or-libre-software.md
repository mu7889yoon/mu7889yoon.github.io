よ〜んです。

最近、OSSや自由ソフトウェアのありがたみについて考えています。

何気なく GNU/Linux を使って、Apache を入れて、MySQL を使って、VS Code でコードを書いていますが、

全て無料で使っています。

でも、もし OSS が存在しなかったら、Web アプリを公開するだけでも、非常にお金がかかるはずです。

ということで、今回はOSSという概念が生まれなかった世界でコスト感を考えてみます。

## GNU/Linuxを使えない世界線では何が台頭するか

OSS がない世界で何が台頭してくるかを考えると、まぁ某窓sだと思います。

構成としては、こんな感じになると思います。

```text
Windows Server
+ IIS
+ SQL Server
+ Visual Studio
```

IIS は Windows Server に含まれているので、HTTP サーバー単体の追加費用は一旦 0 USD として考えます。

ただし、OS や DB や開発環境は普通に有料です。

## 費用感

小さな Web アプリを 1 つ商用運用するだけでも、最低限これぐらいは見ておく必要がありそうです。

| 項目 | 想定 | 費用感 | 参考 |
| - | - | - | - |
| OS | Windows Server Standard | 約 1,176 USD | <https://www.microsoft.com/en-us/windows-server/pricing> |
| HTTP サーバー | IIS | 追加費用なし | |
| DB | SQL Server Standard | 約 989 USD + CAL | <https://www.microsoft.com/en-us/sql-server/sql-server-2022-pricing> |
| 開発環境 | Visual Studio Professional | 約 540 USD / 年 / 人 | <https://visualstudio.microsoft.com/vs/pricing/> |
| 合計 | | 約 2,705 USD + CAL | |

もちろん、これはかなり小さく見積もった場合です。

DB を Server + CAL ではなく Core ライセンスで考えたり、開発者が複数人いたりすると、すぐに金額は増えます。

## 小さな Web アプリでも高い

かなり小さく始めたとしても、初期費用で 3,000 USD 前後。

ちゃんと商用 Web アプリとして考えるなら、数千〜1万 USD 以上は見ておきたいです。

**Web アプリを 1 個公開するだけで**、です。

今なら、個人開発でも小さな会社でも、ほぼ無料で始められます。

## OSS は無料だからすごい、という話ではない

OSS のありがたさは、単に「無料で使える」ことだけではないと思っています。

無料で始められるから、とりあえず試せます。

とりあえず試せるから、学べます。

学べるから、作れます。

作れるから、公開できます。

公開できるから、収益を得ることもできます。

収益が出れば、開発者に還元したり、さらに開発を続けたり、OSS に貢献したりすることもできます。

この流れがあるから、個人開発も、スタートアップも、社内の小さな改善も、かなり身軽に始められているはずです。

## まとめ

今回は、OSS や自由ソフトウェアが存在しなかったら、Web アプリを公開するだけでどれぐらいお金がかかるのかを雑に考えてみました。

もちろん、かなり雑な試算です。

実際には、サーバー台数、DB のライセンス形態、開発者数などで大きく変わります。

普段は当たり前のように使っている GNU/Linux、MySQL、PHP、各種ライブラリ。

それらは、ただ便利な道具というだけではなく、誰かが作り、公開し、直し、守り続けてくれているものです。

OSS と自由ソフトウェアに関わっているすべての方々、いつもありがとうございます。

今日もありがたく使わせていただきます。
